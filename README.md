# 🎵 Track Finder

An ultra-low-latency Web Audio & Music Streaming Engine with Spotify-style Web Client, native Mobile App (Capacitor), and Discord Voice Bot synchronization.

## ✨ Features
- **Ultra-Low Latency Audio Streaming**: Persistent TLS keep-alive sockets, TCP nodelay, and WebM Opus unthrottled streaming (`ratebypass=yes`).
- **3 Channel Output Switcher**: Direct WebAudio (browser), Native Mobile App (Capacitor), and Discord Voice Bot.
- **Trending Playlists**: Bollywood, Punjabi, Sufi, Indie, and Curated Indian Hits with instant progressive playback.
- **Direct Surah Streaming**: 114 Sacred Quran Surahs in high-fidelity audio.
- **Islamic Halal Filter**: Strict Islamic audio filtering modes.
- **One-Click Deployment**: Pre-configured Render Blueprint (`render.yaml`).

## 🚀 Free Deployment on Render (No Card Required)

1. Fork or push this repository to GitHub: `https://github.com/cyber-spy-404/Track-Finder.git`
2. Open the [Render Dashboard](https://dashboard.render.com).
3. Click **New +** ➔ **Blueprint**.
4. Select the **Track-Finder** repository.
5. Click **Apply** to deploy for free.
